# Demo Project (`src/ui/demo.rs`)

The `demo.rs` module provides a predefined project used to showcase the capabilities of Aurora to new users.

## Functionality
It implements `demo_project()`, which returns a fully populated `Project` instance containing:
- Sample tables with realistic experimental data.
- Pre-configured statistical analyses.
- A set of graphs demonstrating various plot types and styles.

This allows users to explore the application's functionality immediately without having to import their own data first.
